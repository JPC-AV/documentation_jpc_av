# JPC Audiovisual Preservation and Archiving Documentation

This repository contains workflow documentation for the audiovisual preservation and archiving project for the Johnson Publishing Company (JPC) Archive, a joint project of the Smithsonian National Museum of African American History and Culture (NMAAHC) and the Getty Research Institute (GRI).

The documentation is split between two repositories. This one holds processing policy: how JPC audiovisual material is arranged and described, and why. The tools repository, [aspace_jpc_av](https://github.com/JPC-AV/aspace_jpc_av), holds the software that moves data between Airtable and ArchivesSpace and links digitized folders, with its setup and operating guides. Each tool also explains itself at the Terminal: `jpc` lists the commands, and `jpc-STEP --help` explains each one.

## Where to find what

- **Install or start using the tools:** [JPC AV Tools Quick Start](https://github.com/JPC-AV/aspace_jpc_av/blob/main/QUICK_START.md).
- **Import, update, check or export data across Airtable and ArchivesSpace:** [Importing and Updating Data](https://github.com/JPC-AV/aspace_jpc_av/blob/main/data_import_export/IMPORTING_AND_UPDATING_DATA.md).
- **Process digitized folders:** [Appending RefIDs to Folders](https://github.com/JPC-AV/aspace_jpc_av/blob/main/refid_appending/APPENDING_REFIDS_TO_FOLDERS.md).
- **Arrange and describe material:** the [JPC AV Processing Manual](JPC_AV_Processing_Manual.md). Useful starting points: [ArchivesSpace fields](JPC_AV_Processing_Manual.md#chapter-0-archivesspace-fields-reference), [where the data lives and how it moves](JPC_AV_Processing_Manual.md#0e-where-the-data-lives-and-how-it-moves), [hierarchy and levels of description](JPC_AV_Processing_Manual.md#chapter-3-hierarchy-and-levels-of-description), [description at each level](JPC_AV_Processing_Manual.md#chapter-4-description-at-each-level) and [titles](JPC_AV_Processing_Manual.md#chapter-5-title).
- **Understand exact field mapping** (optional, technical): [CSV to ArchivesSpace mapping](https://github.com/JPC-AV/aspace_jpc_av/blob/main/data_import_export/docs/CSV_TO_ASPACE_MAPPING.md).
- **See software changes:** the tools' [changelog](https://github.com/JPC-AV/aspace_jpc_av/blob/main/CHANGELOG.md).

The processing manual is the primary guide for arranging and describing JPC audiovisual materials in ArchivesSpace: field conventions, item-level description standards, and DACS/EAD2002 compliance. It complements the broader JPC Archival Processing Manual, which governs the photographic and textual portions of the collection.

The January 2024 ArchivesSpace walkthrough (`aspace.md`) is retired and is not part of current processing.
